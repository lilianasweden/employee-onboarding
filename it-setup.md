# IT Setup Guide

## Laptop Setup

### macOS
1. Sign in with your company Apple ID (IT will provide credentials)
2. Install Managed Software Centre and run all updates
3. Install required tools: Slack, Chrome, Zoom, 1Password
4. Enable FileVault disk encryption (required by security policy)
5. Set up 1Password and add your accounts

### Windows
1. Sign in with your Azure AD account
2. Enrol in Intune MDM (prompt will appear on first login)
3. Install Slack, Chrome, Zoom from the Company Portal app
4. Enable BitLocker encryption (required)

## Accounts to Set Up
| Tool | How to get access |
|------|------------------|
| Slack | Invite sent to your work email |
| GitHub | Create account, request org access in **#it-help** |
| Workday | Link in your welcome email |
| Jira & Confluence | Request in **#it-help** with your team name |
| AWS / GCP | Engineering team only — request from your team lead |

## VPN
Install the VPN client (link in welcome email). You must be on VPN to access internal tools including the HR Knowledge Base, Datadog, and internal APIs.
