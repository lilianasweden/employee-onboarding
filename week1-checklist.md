# Week 1 Checklist

Welcome! Here is everything you need to complete in your first week.

## Day 1 — Admin & Access
- [ ] Sign employment contract in DocuSign (check your email)
- [ ] Set up laptop using [IT Setup Guide](it-setup.md)
- [ ] Join Slack workspace and add your photo and title
- [ ] Join your team channels on Slack
- [ ] Set up Workday (HR system) — link in your welcome email
- [ ] Complete mandatory security training in the LMS (takes ~45 min)

## Day 2–3 — Tools & Systems
- [ ] Set up GitHub account and request access to the org — post in **#it-help**
- [ ] Set up your development environment (Engineering team only)
- [ ] Read the [Engineering Handbook](https://github.com/lilianasweden/engineering-handbook)
- [ ] Schedule intro 1:1s with your immediate team members

## Day 4–5 — Orientation
- [ ] Attend new hire orientation session (HR will send calendar invite)
- [ ] Complete benefits enrolment in Workday — deadline: end of week 2
- [ ] Read the [Education Reimbursement policy](benefits/education-reimbursement.md)
- [ ] Set up 30-60-90 day plan with your manager

## First Month
- [ ] Complete onboarding buddy programme
- [ ] Attend your first team all-hands
- [ ] Submit any initial expenses in Workday
